# Meanders.Tools Components

This directory contains user-facing documentation for Meanders.Tools Grasshopper components.

## Components

### Attributes

- [ME Attribute](./me-attribute.md)  
  Create or modify Meanders object attributes, including name, layer, object color, and user text.

### Objects

- [ME Attach Attribute](./me-attach-attribute.md)  
  Combine geometry or Grasshopper data with Meanders attributes to create ME Objects.

- [ME Detach Geometry](./me-detach-geometry.md)  
  Separate ME Objects into their stored geometry and attributes.

### Utilities

- [ME Unit Converter](./me-unit-converter.md)  
  Convert numerical values between supported length units.
