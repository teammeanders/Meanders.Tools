# Component Definition of Done

A component is considered complete only when all items below are satisfied.

- Final component name
- Final nickname
- Unique ComponentGuid
- Correct category
- Correct subcategory
- Complete component description
- Correct input names
- Correct input nicknames
- Correct input descriptions
- Correct input types
- Correct input access types
- Optional/default values defined
- Correct output names
- Correct output nicknames
- Correct output descriptions
- Correct output types
- Component icon available
- Component metadata JSON created
- Documentation page created
- At least one usage example available
- Tested in Rhino/Grasshopper
- Version assigned
- Release status defined
